### 🍅 Pomo

> A minimalist, terminal-native Pomodoro timer built with **Rust** and **Ratatui**, featuring companion pets that keep you focused (or roast you when you pause)

---

### Features

* **Terminal UI (TUI):** Built with `ratatui` and `crossterm` for decent UI and control
* **Pet Companions:** Choose your focus buddy—including **Pomo** (Cat), **Shelly** (Turtle), **Barkley** (Dog), **Hop** (Bunny), or **Linus Torvalds** (Kernel Engineer).
* **Night Mode:** Other pets wont be avalable at night only the Hoot will (Hoot is an Owl).
* **Desktop Notifications:** You will also get Desktop Notifications from the pets on [breaktime - start and end, Compleation].
* **Persistent Config:** Remembers your selected companion across sessions via `config.toml`. [not too strong feature yet - but it just works]
